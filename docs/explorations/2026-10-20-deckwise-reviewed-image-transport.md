# Reviewed image transport consolidation

A34's released four-file Office consumer overlay is now present in B's Office producer, alongside B60's PNG chunk-integrity guard. This keeps the product embed transport and native image consumer in one source snapshot. Parent-origin/session checks, reviewed immutable metadata, fresh command-scoped bytes, finite image commands and explicit save remain separate from C authorization. Server membership/review and account/Chat/source lifetime remain Main responsibilities.

No second bridge instance or production fixture installer is needed. Standard production editor entries receive `document:review-image` and `document:execute-image`; exact fields and byte lifetime are documented in both embed API documents. Tests cover reset during pending execution and rejection of concurrent byte leases. B61's parent-workspace handoff records the original overlay hash, minimally applicable B60 CRC patch for A34, actual embed validation and preserved A sources.
